# Maintenir le contexte AIDD

Mettre à jour les fichiers de `memory/` lorsque les décisions ou l'état du projet changent. Garder les faits vérifiables et renvoyer à la documentation ou au code pour les détails. Après ajout ou suppression d'un fichier mémoire, synchroniser les blocs AIDD de `AGENTS.md` et `CLAUDE.md` avec le hook AIDD.
