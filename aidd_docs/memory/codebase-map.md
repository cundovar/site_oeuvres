# Repères du dépôt

- `front/` : application Next.js ; point d'entrée de la page `front/app/page.tsx`.
- `back/` : application Symfony ; point d'entrée HTTP `back/public/index.php`.
- `docs/` : documentation VitePress ; `compose.yaml` : services de développement.
- `.github/workflows/ci.yml` : contrôles GitHub Actions.
