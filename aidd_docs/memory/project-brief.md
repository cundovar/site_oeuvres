# Projet

- Futur site d'art ; le design system, les pages et les composants sont préparés dans Penpot local.
- Modèle métier (œuvres, séries, catégories, médias) implémenté côté base le 27 novembre 2026 ; l'administration, l'API et le front ne l'exposent pas encore. Ne pas présenter les idées comme des fonctionnalités existantes.
- Décisions de conception validées le 27 novembre 2026, non implémentées : schéma multilingue dès le départ (une langue par champ traduisible) avec publication en français seul ; menu public Œuvres · Séries · Films · À propos · Contact identique sur ordinateur et mobile, entrée courante mise en évidence ; administration sans constructeur de pages, une œuvre a une série unique et plusieurs catégories.
